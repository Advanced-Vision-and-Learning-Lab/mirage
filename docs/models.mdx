## Add a model

A model is a class in `models/` with `load_model`, `unload_model` and `generate(prompt, image, **gen)`, which returns the answer text. A chat model that takes one image and one text turn can subclass `HFChatVLM`, as Aya Vision does. Register it with one row in `REGISTRY` in `predict/factory.py` and one line in `_MODULES` in `models/__init__.py`, then run it with `--model <key>`.

```python models/aya_vision.py
from .hf_chat import HFChatVLM


class AyaVision(HFChatVLM):
    """Aya Vision; keys its cache as ``HFChatVLM``."""
```

```python predict/factory.py
"aya-vision-8b": Entry("models.aya_vision:AyaVision", "MIRAGE_AYA_VISION_8B_MODEL_PATH",
                       "CohereLabs/aya-vision-8b", "HFChatVLM", _BF16),
```

The registry row gives the class, the variable that holds the local model path, the default Hugging Face id, the cache name and the dtype. `build_predictor(key)` wraps the model in a [Predictor](/predict), and the cache name is part of every cache key, so keep it fixed once you have results. A new model's judged scores need verdicts for its own caption mentions, so run it once with `--live-judge`.

## Thinking ablation

This is separate from the main results. It uses standard COCO POPE, not Mod-POPE, on the same 500 images and 2,641 questions in both modes. With thinking on, the model gets 1,024 extra tokens on top of the 10-token POPE cap.

| Model | Thinking | Accuracy | Precision | Recall | F1 | Predicted "yes" |
|---|---|---:|---:|---:|---:|---:|
| Gemma-4-12B | off | 93.0% | 97.8% | 85.8% | 91.4% | 37.9% |
| Gemma-4-12B | on | 94.1% | 97.7% | 88.4% | 92.8% | 39.1% |
| Gemma-4-E4B | off | 93.5% | 94.2% | 90.6% | 92.4% | 41.6% |
| Gemma-4-E4B | on | 93.8% | 95.6% | 89.7% | 92.6% | 40.6% |

Gemma-4-12B gains 1.1 points: false negatives fall from 162 to 132, and false positives go from 22 to 24. Gemma-4-E4B gains 0.3 points and gets more cautious: false positives fall from 64 to 47, and false negatives rise from 107 to 117. A thinking run takes 8 to 11 GPU hours, against about 40 minutes with thinking off. Captions, CHAIR and THRONE were not run with thinking on, since each caption takes 130 to 145 seconds, about 6 times the cost.

In 11 of the 2,641 Gemma-4-12B answers (0.4%), the thought did not close within 1,034 tokens. Gemma-4-E4B closed every thought. The wrapper logs `Thinking block not closed` and returns the cut-off thought as the answer. The POPE parser checks for negative words first, so all 11 count as "no". At worst, scoring them right would raise accuracy by 0.4 points, to 94.5% or less.

The keys are `gemma4-e4b-think` and `gemma4-12b-think`. They use a separate class, so their cache keys never mix with thinking off, and they have no judged scores.
