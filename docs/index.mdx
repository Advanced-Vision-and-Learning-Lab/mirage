title: "Mirage"
description: "Run vision-language model hallucination evaluations on COCO and Visual Genome."
---

Mirage is a research codebase for running visual object hallucination evaluations with vision-language models. The repository includes dataset loaders for COCO and Visual Genome, model adapters for PaliGemma and Qwen2-VL, and implementations of several evaluation metrics.

The `demo.py` command provides a single entry point for running an evaluation and optionally writing its results to JSON. These guides focus on the runnable workflow, expected local data layout, and metric and model implementations in the repository.
