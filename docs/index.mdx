---
title: "Mirage"
description: "A vision language model eval framework with modified hallucination metrics."
---

Mirage is an evaluation framework for vision language models. It measures object hallucination with four metrics from the literature: POPE, ROPE, CHAIR and THRONE. Each metric is modified so it still works on datasets with sparse labels, such as Visual Genome.

## Results
