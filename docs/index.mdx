Vision-language models can describe objects that are not present in an image as fluently as those that are. Comparing hallucination metrics is difficult because important protocol choices—such as prompt wording, decoding settings, answer parsing, ground-truth annotations, and judge models—are often implicit in separate evaluation scripts.

**Mirage** is a modular framework for implementing and comparing these evaluation protocols. It separates model inference, dataset handling, and metric scoring behind shared interfaces. Its persistent prediction cache also lets researchers rescore generated responses without repeating model inference. Mirage makes protocol choices easier to inspect and experiment with; it does not erase the methodological differences between metrics.

The `demo.py` command is the runnable entry point in this repository. It supports COCO and Visual Genome data, PaliGemma and Qwen2-VL model wrappers, and the POPE, ROPE, CHAIR, THRONE, NOPE, and FaithScore metric implementations.

## Thesis evaluation scope

The thesis evaluated three instruction-tuned models—PaliGemma-3B-mix-224, Qwen2-VL-2B-Instruct, and Qwen2-VL-7B-Instruct—using 1,000 images from each of COCO and Visual Genome and four metrics: POPE, ROPE, CHAIR, and THRONE. NOPE and a reduced FaithScore implementation are included in the toolkit but were not part of those reported evaluation runs.

The thesis reports that replaying every reported result from the prediction cache reproduced its original result file exactly. This makes the cached outputs useful for studying how scoring and grading choices affect a result without rerunning model inference.
