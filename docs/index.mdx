---
title: "Mirage"
description: "A vision language model eval framework with modified hallucination metrics."
---

Mirage is an evaluation framework for vision language models. It measures object hallucination with four metrics from the literature: POPE, ROPE, CHAIR and THRONE. Each metric is modified so it still works on datasets with sparse labels, such as Visual Genome.

## Results

Nine models, scored on the same first 500 images of COCO val2017 and Visual Genome. Tables show headline modified scores as percentages; ranks are in parentheses, with 1 best. Bold marks the highest score in each column. Select the GPT-6.1 Sol tab to compare Visual Genome POPE rankings under the two judges and the original POPE Accuracy ranking.
