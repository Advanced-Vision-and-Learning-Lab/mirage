Mirage reports four hallucination metrics: POPE, ROPE, CHAIR and THRONE. Each keeps what its paper measures and how it scores. A metric is modified only where a dataset breaks it, mainly Visual Genome's sparse, free-text labels. Every modification is named here, and a metric that departs from its paper in a way a reader would notice carries a **Mod-** prefix.

The headline tables use the shared first 500 images of each dataset for all nine models, without confidence intervals; sample sizes are reported instead.

## How scoring works

- Scores are computed from cached model outputs and static judge files in [`judgments/`](https://github.com/Advanced-Vision-and-Learning-Lab/mirage/tree/main/judgments): mention verdicts, ROPE verdicts and the POPE drop list. Scoring never calls a judge.
- An item with no verdict, for example from a new model, stops scoring with a list of the missing items. They are graded with [`tools/judge`](https://github.com/Advanced-Vision-and-Learning-Lab/mirage/tree/main/tools/judge) and appended to the judgment files.
- The judge is Claude (`claude-opus-5-5`) run headless with one skill per task: `judge-mentions` (rubric v3.1), `judge-rope` (v1) and `judge-pope` (v1). Each call sees 2–10 images.
- Rescore with `python -m metrics.judged --root <results tree> --out final_tables.json`. `tests/test_final_tables_repro.py` checks that this reproduces all 198 reference values.

**Completed labels.** For Visual Genome, an object counts as present if it is annotated, or if a model mentioned it and the judge verified it in the image. Unsure verdicts count on neither side. The pool of verified objects depends on the evaluated models, the rubric version and the judge model, so all three are stated with the results.

**Minimum response.** A caption under 5 words counts as saying nothing: it mentions no objects and receives an empty prediction rather than being skipped.

## POPE → Mod-POPE

**Paper:** yes/no questions "Is there a {object} in the image?", half about annotated objects and half about absent ones, scored by accuracy.

**What breaks:** Visual Genome "no" questions draw their object from all 82,827 free-text names. Of the 1,500 on the shared images, 301 (20.1%) are junk names ("stillness", "blk"), 33 (2.2%) are visible, and 194 (12.9%) cannot be verified from the image. COCO has 0 junk, 7 visible and 34 unverifiable.

**Mod-POPE:**
- Questions and answers are unchanged. The no-questions in `judgments/pope_drop_list.tsv` are removed: junk names, judge-verified present and judge-unsure (528 on Visual Genome, 41 on COCO).
- The headline is **balanced accuracy**, because the remaining set is 54–60% yes and plain accuracy would favour yes-leaning models. The paper's 50/50 design is base-rate neutral, and balanced accuracy keeps that property. COCO's raw set is not 50/50 (1,141 yes / 1,500 no), so balanced accuracy alone moves some COCO models; the appendix shows each step.
- Secondary: F1 and yes-ratio, which shows a yes/no lean such as Ministral 3's "No".

## ROPE → Mod-ROPE

**Paper:** numbered boxes are drawn on the image, and the model names the object in each box. The answer is graded against the dataset class of that box.

**What breaks:**
- Visual Genome boxes rarely hold one object: only 214 of 2,500 queried boxes are clean, against 1,399 on COCO. A road box with a car on it marks "car" wrong.
- Visual Genome class names are one annotator's free text ("apartment" vs "building").
- The strict extractor truncates answers ("piece of cake" → "piece").

**Mod-ROPE:**
- Prompts and answers are unchanged. The answer is the first noun phrase of the reply; for a hedge ("X or Y"), the first option.
- The judge grades whether the answer fairly names an object filling a substantial part of the box: correct, related, wrong or unsure.
- The headline is correct ÷ (correct + related + wrong); unsure boxes are excluded. Secondary: strict accuracy against the dataset class (paper-style), the related rate, and the score with unsure counted as wrong.
- For Gemma-4-12B on Visual Genome, strict accuracy is 21.4, the parser fix alone 35.6, and judged 65.5. Box-overlap answer sets were tried and rejected: they help little ("≥80% inside", +1–3) or are too generous to defend.

## CHAIR → Mod-CHAIR

**Paper:** caption words are matched against the COCO-80 vocabulary with a synonym list. Truth is the segmentation labels plus objects named in the five reference captions. CHAIR-I is hallucinated ÷ mentioned, CHAIR-S the share of captions with a hallucination; lower is better.

**What breaks:**
- On Visual Genome every name is vocabulary, so tokens like "has", "shows" and "front" count as objects: 30–37% of the chatty models' flags are not nouns in context.
- Labels are sparse: raw Visual Genome CHAIR-I is 64–88%, but the verified rate is 1–7%.
- CHAIR-I alone rewards saying less. PaliGemma writes 115 of 500 Visual Genome captions under 5 words.

**Mod-CHAIR:**
- Truth is completed labels, plus the reference-caption objects on COCO, as in the paper.
- Mentions are nouns in context (NLTK tagging), counted once per caption. A plural, phrase, synonym or hypernym of an annotation counts as present; any other non-annotated noun takes the judge's verdict.
- **Coverage** is the share of pooled verified objects (named by any model and present) that the caption names.
- The headline is **Mod-CHAIR F0.5** = F0.5(1 − Mod-CHAIR-I, coverage), using THRONE's β = 0.5, which weighs hallucination twice as much as coverage. Secondary: Mod-CHAIR-I, coverage and Mod-CHAIR-S.

## THRONE

**Paper:** for each object category, FLAN-T5 evaluators answer whether the caption mentions or implies the object. Truth is exhaustive annotations, and the headline is **class-wise F0.5**: precision and recall averaged over categories, then F0.5.

**Mirage:**
- Class-wise F0.5, as in the paper. The earlier Mirage tables reported per-image F1, which compressed Visual Genome to 25.5–27.9 for all models.
- Evaluator: FLAN-T5-XL with three phrasings, unanimous, and a 1,024-token input so no caption is trimmed. The paper's ensemble adds Base and Large (nine votes); a test on Gemma-4-12B COCO moved class-wise F0.5 from 79.0 to 82.0, mostly by dropping split votes, and the full run was declined on cost.
- Each image is asked about its annotated categories plus 38 distractors per annotated category (all categories when fewer remain), because Visual Genome's vocabulary is too large to ask every category.
- Captions under 5 words predict nothing; on PaliGemma's one-word captions the evaluator otherwise marks about 30 categories present per image.
- Visual Genome truth is completed labels, and its average covers only categories with at least 5 annotated images (319 categories); COCO averages over every category.

## Footnotes

- PaliGemma-3B writes 27 COCO and 115 Visual Genome captions under 5 words, which score as empty.
- Qwen2-VL-2B answers COCO ROPE boxes with coordinates, which grade as wrong.
- One Qwen2-VL-7B Visual Genome caption was trimmed for THRONE at the earlier 512-token limit and was not re-judged (effect at most 0.1 points).
- Coverage pools the objects any of the nine models named, so it depends on the model set.
